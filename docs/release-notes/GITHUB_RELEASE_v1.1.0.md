## Dynamic Encounter Tracker 1.1.0

### Highlights

- Optional minimal mode for the status window: a compact single-line display instead of the full window
- A second line appears automatically once participation in the encounter is confirmed
- Toggle button next to the close button for quickly switching between minimal and normal mode
- Window width and height in minimal mode adjust automatically to the current text
- Independent settings to show or hide the close button and the minimal-mode toggle button

### Fixed and improved

- Fixed redundant internal panel refresh calls in the settings window (thanks to Baertram for the report)

### Requirement

- LibAddonMenu-2.0 r43 or newer
